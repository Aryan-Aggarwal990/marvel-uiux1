# /public/assets/characters

Put licensed or approved hero artwork here. Then set that hero's `image` field in
`src/config/characters.ts`, for example `image: '/assets/characters/thor.png'`.

Until then (or if a file is missing or fails to load), the built-in stylised SVG portrait
is shown, so the layout never breaks.

- **Recommended format:** transparent PNG or WebP, portrait 4:5 (e.g. 1200×1500), bust framing
  with the head in the upper two thirds.
- **Suggested file names:** `spiderman`, `ironman`, `strange`, `panther`, `thor`, `hulk`,
  `cap`, `marvel`, `wanda`, `loki`, `miles`, `deadpool` (`.png` / `.webp`).
- **Licensing:** only use artwork you have the rights to publish (official press kits, commissioned
  art, or art supplied by the event organisers). Don't use images scraped from the internet.
